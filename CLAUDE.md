# Правила работы с проектом

## Переработка контента

- Запрос «перерабатываем пункт N» означает пункт N раздела «Переработка контента блога»
  в `BACKLOG.md`. Выполнять строго по «Порядку выполнения любого пункта» из того же
  раздела и трогать только статьи и перенаправления этого пункта.

## Git

- Вся работа ведётся в ветке `dev`: коммиты и пуши только в `dev`.
- В `main` ничего не коммитить и не пушить. Pull request'ы в `main` не создавать.
  Слияние `dev` → `main` владелец делает сам, вручную, через интерфейс GitHub.
- После завершения задачи не спрашивать про PR или merge в `main`.
- Коммитить и пушить в `dev` только по просьбе владельца.
- Все действия с репозиторием выполняются от имени владельца. Не указывать Claude
  как автора или соавтора: никаких строк `Co-Authored-By: Claude…`, «Generated with
  Claude Code» и подобной атрибуции в коммитах, pull request'ах, issue и комментариях.
